# Security Policy

This repository is an independent reference design, not an OpenAI product.

Please do not use public issues for credentials, personal files, private source, or a vulnerability that could affect deployed systems. Report vulnerabilities in the software you are assessing through that project's official security policy.

For this reference implementation, open a private advisory in the repository hosting it or contact its maintainer. Include the affected version, platform, minimal reproduction, expected/actual behavior, and whether the issue breaks a stated security invariant.

The Python implementation must not be represented as a standalone OS sandbox. See `docs/PRODUCTION_HARDENING.md`.
